视觉设计规范 · DESIGN SYSTEM v2.0

让营地地图看起来像一个
正经打磨过的产品，而不是演示页

保留现有架构（零构建、零依赖部署），不引入任何框架。这一版从色彩、字体、间距、阴影、动效五个层面建立统一语言，浮在地图上的每一块面板都遵循同一套规则。

自然材质深林绿 + 落日橙 + 暖白纸感背景，贴合户外露营气质
浮层通透地图之上的界面一律毛玻璃，内容不被遮挡、层次清晰
克制动效只在该反馈的地方动：悬停浮起、按下回弹、内容滑入
